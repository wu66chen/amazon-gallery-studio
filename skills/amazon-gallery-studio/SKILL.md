# 商品套图 · 运营试用版

Read `AGENTS.md` if present in the current project. This skill is bound to the **current project's** `scripts/` and `任务资产与审批/`. An external directory supplied by the user is **only a source of images**; never create a task folder there or use it as a project root. Resolve project root as the parent of the installed skill's `scripts/` directory, not the source path or terminal cwd. Do not copy project files or keys into source folders. Install `requirements.txt` before image generation.

## One uninterrupted path

1. **Import.** User supplies a Finder path (file or directory), or attaches images. For a file attachment, use its actual readable local file bytes/path; if the harness exposes no bytes, request a saved file path once. Import with `python3 scripts/task_assets.py --set-name <商品名称> --source <external file or directory>`. Repeat `--source` when needed. The importer scans only direct image children, copies external files into `<project>/任务资产与审批/01_原始素材/<set>/`, preserves originals and user-placed files, and never imports an unrelated `任务资产与审批` subtree. Its `--project` option, if supplied, **must equal the installed script's project root**.
2. **Recognize automatically.** Once readable images exist, run `python3 scripts/plan_gallery.py --vision --images <imported files> --product <optional user name>`. This script loads `TOKEASE_API_KEY` from the **current project's `.env`**, sending actual image bytes through `https://tokease.com/v1/chat/completions` with exact model ID `gemini-3.5-flash`. Initial recognition is included automatically when the operator starts a gallery task; do not ask a separate recognition permission or budget cap. If the key or input is missing, state that one blocker concisely. Never ask the main OpenCode model to visually inspect an attachment after it reports no image support; the script performs recognition independently.
3. **Copy and white-background choices.** If no exact copy or explicit no-copy instruction is supplied, ask once: `1` user supplies copy, `2` agent suggests fact-grounded copy, `不要文案` no copy. If vision identifies a reusable white-background source image, ask in the same planning turn: `沿用现有` / `生成新的` / `不需要白底`. This is a **separate decision** from copy. A white source photo is only a candidate; check actual Amazon main-image suitability before reuse. If no white source exists, only ask about a white main image when the planned publication placement needs one. Never silently regenerate a usable supplied white-background asset.
4. **Propose in chat.** Show a small Markdown table with columns `编号 | 发布位置 | 看点 | 场景/构图 | 文案状态`, preceded by the product identity, style direction and number of references. Show the **single combined estimated API cost** for the planned number of images. Group copy and white-background choices into this one planning turn. Once the operator accepts the plan and estimate, proceed to generating the representative—do not request another approval of its prompt or concept.
5. **Copy.** User-provided copy is locked verbatim. If mode `2`, show the candidates in the chat and record them as `系统建议待确认`; they do not enter the prompt until the user accepts them. If `不要文案`, record `明确无文案` and stop asking. No text on an Amazon official main image. Never invent performance, material, certifications or numerical specs.
6. **Representative.** After the user approves the plan, copy mode/candidates and combined cost estimate, mark the matching plan JSON `confirmed=true`, then call `python3 scripts/generate_representative.py --set-name <set> --plan <approved JSON> --prompt-file <approved prompt> --image <imported file>`. It reads **the same** `TOKEASE_API_KEY` from project `.env` and calls `gpt-image-2` via Tokease `https://tokease.com/v1`. Do **not** use `GPTIMAGE_API_KEY`, GPT Image 2.5, or a third-party website. The CLI writes the image into this project's `02_代表图审批/<set>/`. Inspect actual dimensions and run Gemini-based original-vs-generated QA before showing it. If a hard defect is found, repair it within the approved cost estimate or report the blocker; never represent a prompt or plan as a finished image.
7. **Approval is an execution trigger.** Show the actual representative image and a short QA summary in chat. Ask `是否批准这张代表图的产品外观、画面方向和文案处理方式？批准后我会直接生成其余已确认图片。` When the operator replies `批准` / `通过` / `同意`, **in the same turn** run `python3 scripts/gallery_workflow.py --set-name <set> --plan <approved JSON> --representative <approved image> --execute`. This archives the accepted image in `03_最终套图/<set>/`, then runs `scripts/finish_gallery.py` on the rest. Only the accepted version is promoted; rejected drafts stay in `02_代表图审批/<set>/`. Do not stop at "已记录批准" and do not ask for a second "继续". If an API/QA error blocks execution, report that exact blocker and keep the task pending.
8. **Complete the gallery.** The batch runner stores remaining generated images in `03_最终套图/<set>/`, performs technical and Gemini original-vs-result checks, then places `套图总览.jpg` and `最终审核报告.md` beside the images. A reused white-background reference is a *candidate* for an Amazon main image until actual background and category suitability have been checked. Present the overview and issues in chat for final human review. Technical or automated-vision pass does not claim marketplace upload approval.

## Communication

Use stage-appropriate short paragraphs or a small table, not a fixed multi-heading form. Put the approval question last and make the action concrete. Do not repeat the absolute task path after it has already been shown unless the path changes or the user asks. Keep lengthy prompts, raw model output, technical traces, and records in `任务资产与审批/04_记录与报告/`. Show the **plan and representative direction in the conversation**, not just as a file reference. If a file is not actually generated, say so plainly and keep the task open.

The project includes source import, planning, representative generation and a paid batch runner. Before calling the runner, verify the approved plan's `confirmed`, `copy.confirmed`, `white_background.confirmed`, `cost_estimate_approved` and `representative_approved` fields. A gallery remains pending final human review until the operator accepts its results.
